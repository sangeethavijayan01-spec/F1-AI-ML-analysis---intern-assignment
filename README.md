# F1 AI/ML Analysis

## Project Overview
This project analyzes Formula 1 Bahrain GP 2024 race data using FastF1, performs data cleaning, exploratory data analysis, feature engineering, machine learning-based lap time prediction, and anomaly detection.

## Technologies Used
- Python
- FastF1
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
